# Review Checklist

## Business

- [ ] Đúng phạm vi.
- [ ] Không tự phát minh rule.
- [ ] Transition hợp lệ.
- [ ] Audit đầy đủ.

## Backend

- [ ] Authorization.
- [ ] Validation.
- [ ] Transaction.
- [ ] Không N+1.
- [ ] Query có index phù hợp.
- [ ] Không log secret.
- [ ] Upload an toàn.
- [ ] Side effect đúng chỗ.

## Frontend

- [ ] TypeScript.
- [ ] Loading/empty/error.
- [ ] Responsive.
- [ ] Permission-aware.
- [ ] Không duplicate request.
- [ ] Accessibility.

## Testing

- [ ] Happy path.
- [ ] Forbidden.
- [ ] Validation.
- [ ] Business rule.
- [ ] Rollback.
- [ ] Side effect.

## Delivery

- [ ] Migration/command được ghi rõ.
- [ ] Tài liệu cập nhật.
- [ ] Không còn TODO không giải thích.
- [ ] Build và test chạy thành công.
